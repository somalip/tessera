A little help with your code.

Halfway through a line? Tessera can suggest what comes next. Stuck on a function? Ask in chat. Both run in VS Code with small models on your machine.

One file, two languages

A Python file can have a little SQL tucked inside it. Put your cursor in the query and Tessera can switch to a SQL model. Move back to the surrounding code and it can switch back to Python.

If you’d rather stick with one model, pin it to a file or workspace. Each Tessera model package is under 1 GB, and the model uses some extra memory while it runs.

Downloads

Open a GitHub release and look under Assets for the VS Code installer (.vsix) and model files.

Model licenses
  • Original coding model. The upstream Qwen2.5-Coder-0.5B weights are licensed under Apache License 2.0 (Apache-2.0).
  • Python autocomplete and structured-data autocomplete. Both are based on Apache-2.0 Qwen2.5-Coder-0.5B weights. The Python model has a merged LoRA update. The structured-data model uses the stock weights in Q4_K_M format.
  • Standalone Python models. The configured generator and experimental LoRA candidate are based on Qwen2.5-Coder-1.5B, whose upstream weights are licensed under Apache-2.0.
  • Documentation, English editing, diagrams, and summaries. All four experimental variants use Apache-2.0 Qwen3.5-0.8B weights with task-specific chat templates. The TCM archives include the Apache-2.0 license text.

Set up in VS Code

Grab the VSIX installer and a compatible GGUF model, then open the Command Palette.

  1. Run Extensions: Install from VSIX… and select the installer.
  2. Run Tessera: Open Dashboard.
  3. Choose Add Local GGUF, select a model role, and open the GGUF file.

What we learned from fine-tuning

We used LoRA to fine-tune two Python models. The 354 MB Qwen2.5-Coder-0.5B autocomplete model trained on 96 original examples of comments and partial lines. The 935 MB standalone-program candidate trained for two epochs on 48 verified examples.

The fine-tuned autocomplete model reached its first token in a median of 75 ms on CPU, compared with 167 ms for the stock model. The standalone candidate tied the configured checkpoint on full programs and passed 1 of 16 short Python chat tests, compared with 4 of 16 for the configured checkpoint. The release kept the latter for Python generation.

The four experimental Qwen3.5-0.8B variants use shared weights and task-specific chat templates. The smoke checks passed 2 of 4 for documentation, 1 of 1 for English editing, 3 of 3 for diagrams, and 2 of 2 for summaries.

Security policy

This policy covers the Tessera VS Code extension, its local model runtime, and model packages and downloads distributed by Tessera.

Where your code goes

Prompts and editor context stay on the machine during inference. Tessera records usage metrics locally.

How Tessera checks model downloads

Registry lookups and model downloads connect to their configured sources. When you install from a remote Tessera registry, the extension checks the index and the downloaded package.

Report a vulnerability privately

Use Tessera’s GitHub Security Advisories and choose Report a vulnerability. If the private form is unavailable, contact the maintainers through an established private channel. Keep vulnerability details out of public issues and pull requests.

  • Include the affected Tessera version, operating system, and model or download source if relevant.
  • Describe how to reproduce the issue and what impact it could have.
  • Remove credentials, personal paths, and private code from logs and examples.

Please coordinate public disclosure with the maintainers so users have time to update.
