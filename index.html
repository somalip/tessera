How model selection works

In a Python file like this, Tessera can use a SQL model while you edit the query and a Python model elsewhere in the file.

You can pin a model to a file or workspace. Tessera’s model packages are under 1 GB each. Running a model also uses memory for its context and runtime buffers.

Set up in VS Code

Once you have the VSIX installer and a compatible GGUF model:

  1. Run Extensions: Install from VSIX… from the Command Palette and select the installer.
  2. Run Tessera: Open Dashboard.
  3. Choose Add Local GGUF, select a model role, and open the GGUF file.

Experimental specialty models

The documentation, English editing, Mermaid, and summary variants share the Qwen3.5-0.8B Q8_0 weights and tokenizer. Each adds specialty instructions through its GGUF chat template. Raw completion calls that bypass the template skip those instructions.

Security policy

This policy covers the Tessera VS Code extension, its local model runtime, and model packages and downloads distributed by Tessera.

Report a vulnerability privately

Open Tessera’s GitHub Security Advisories and select Report a vulnerability if the option is available. If the private form is unavailable, contact the maintainers through an established private channel and keep the details out of public issues and pull requests.

Include the affected version, operating system, model or download source if relevant, steps to reproduce the issue, and the potential impact. Before sharing logs or examples, remove credentials, personal paths, and private code. Please coordinate public disclosure with the maintainers so users have time to update.

Local inference and download integrity

The extension sends prompts and editor context to its local inference server on the same machine. Extension usage metrics stay local. Registry lookups and model downloads connect to their configured sources. Tessera verifies signatures on remote registry indexes and checks downloaded model files against their expected SHA-256 hashes.
