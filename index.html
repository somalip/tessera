Python fine-tune

Both versions start from Qwen2.5-Coder-1.5B-Instruct. The Python version uses LoRA to update a subset of the weights using eight Python examples that passed sandbox tests. The updates are merged into a 935 MB GGUF that runs locally.

In an eight-task Python chat benchmark, the tuned model fixed an integer duration calculation that the untuned model missed. The untuned model passed a JSON record decoding task that the tuned model missed. Both scored 2 of 8 overall.

With the capsule router, both 1.5B versions passed the same log summarization task on their first try, scoring 1 of 8 each. The smaller 0.5B baseline scored 0 of 8. The duration repair is one observed strength. These tests found no overall gain over the untuned 1.5B model.

General-purpose variants

The documentation, English editing, Mermaid, and summary variants use the original Qwen3.5-0.8B Q8_0 weight tensors and tokenizer. Their GGUF metadata sets general.name and general.description for each specialty.

Each variant adds a Jinja preamble to tokenizer.chat_template. It creates a system message with the specialty instructions or prepends them to an existing system message, then runs the original Qwen template.

llama.cpp renders the template before tokenization, so the specialty instructions become part of the model input. Raw completion calls that bypass the chat template skip those instructions.

Install

  1. Run make vsix and install artifacts/tinycoders.vsix in VS Code.
  2. Open the TinyCoders dashboard and add a local Qwen2.5-Coder GGUF.
