Developer tools that run locally.

    
Rusk builds software for developers who want to work with models on their own hardware. We design around the tools developers already use and the machines they already have.


    

      
Products

      
Tessera is our first product. It brings local code completion and chat to VS Code, selecting a compact model for the language at your cursor. Every model package is under 1 GB.

      
Download Tessera or read the architecture.

    


    

      
Company

      
Rusk is the company behind Tessera. We build around local hardware limits, fit into the editor developers already use, and keep inference on the same machine.
